INTRODUCTION                                                       *blink-calc*

blink-calc is a blink.cmp source that evaluates math expressions as you type,
similar to cmp-calc.

Links:
- Changelog: https://github.com/joelazar/blink-calc/blob/main/CHANGELOG.md

FEATURES                                                  *blink-calc-features*

- Evaluates math expressions in real-time as you type
- Basic arithmetic operations: `+`, `-`, `*`, `/`
- Parentheses for complex expressions
- Lua math library functions (`sin`, `cos`, `sqrt`, ...) plus `ln`, `log2`,
  `log10`, `mod`
- Constants: `pi`, `e`, `phi`, `tau`
- Factorial `5!` and combinatorics: `fact`, `gcd`, `lcm`, `perm`, `comb`
- Statistics: `sum`, `avg`, `mean`, `median`, `min`, `max`
- Bitwise functions: `band`, `bor`, `bxor`, `bnot`, `lshift`, `rshift`
- Percentages: `20% of 150`, `150 + 20%`, `50%`
- Number bases: `0xFF`/`0b1010` input and optional hex/binary result items
- Digit separators in input (`1_000_000`) and optional grouped result items
- Configurable result precision and equation separator
- The bare result, the full `expr = result`, and optional base/grouped items

================================================================================
REQUIREMENTS                                          *blink-calc-requirements*

- Neovim ≥ 0.12.2
- blink.cmp (https://github.com/Saghen/blink.cmp)
- StyLua (https://github.com/JohnnyMorganz/StyLua) for formatting and linting
- LuaLS (https://github.com/LuaLS/lua-language-server) for type checking
- Make (https://www.gnu.org/software/make/) for build and test commands

================================================================================
INSTALLATION                                          *blink-calc-installation*

Using lazy.nvim, register blink-calc as a blink.cmp provider:

>lua
  {
    "saghen/blink.cmp",
    dependencies = { "joelazar/blink-calc" },
    opts = {
      sources = {
        default = { "lsp", "path", "snippets", "buffer", "calc" },
        providers = {
          calc = {
            name = "Calc",
            module = "blink-calc",
            opts = { show_equation = true },
          },
        },
      },
    },
  }
<

================================================================================
CONFIGURATION                                               *blink-calc-config*

Options are passed through the blink.cmp provider `opts` table:

>lua
  {
    show_equation = true, -- extra "expr = result" item when typing '=' (boolean)
    show_bases = false,   -- extra hex/binary items for integer results (boolean)
    group_digits = false, -- grouped item for large integers; true uses ',' or a custom separator string
    precision = 10,       -- decimal places used to tame floating-point noise (integer)
    separator = " = ",    -- text between expression and result in the equation item (string)
  }
<

================================================================================
USAGE                                                        *blink-calc-usage*

Type a math expression and the completion menu shows the result:

- `2+2=`           → `4` and `2+2 = 4`
- `10*5+3`         → `53` and `10*5+3 = 53`
- `sqrt(16)`       → `4`
- `5!`             → `120`
- `gcd(12,18)`     → `6`
- `avg(2,4,6)`     → `4`
- `20% of 150`     → `30`
- `150 + 20%`      → `180`
- `band(12,10)`    → `8`
- `0xFF`           → `255` (with `show_bases`, also `0xFF`, `0b11111111`)
- `1_000_000`      → `1000000` (with `group_digits`, also `1,000,000`)

TROUBLESHOOTING                                    *blink-calc-troubleshooting*

First, run the health check:
>vim
  :checkhealth blink-calc
<

Then reproduce in a clean environment:

1. Clone blink-calc and cd into the directory
2. Run `nvim -u repro/repro.lua`
3. Run `:checkhealth blink-calc`
4. Reproduce the issue
5. Report repro.lua and any error messages
