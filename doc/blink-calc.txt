INTRODUCTION                                                       *blink-calc*

blink-calc is a blink.cmp source that evaluates math expressions as you type,
similar to cmp-calc.

Links:
- Changelog: https://github.com/joelazar/blink-calc/blob/main/CHANGELOG.md

FEATURES                                                  *blink-calc-features*

- Evaluates math expressions in real-time as you type
- Basic arithmetic operations: `+`, `-`, `*`, `/`, power `^`
- Parentheses for complex expressions
- Lua math library functions (`sin`, `cos`, `sqrt`, ...) plus `ln`, `log2`,
  `log10`, `mod`
- Trigonometry in radians or degrees (`angle = "deg"`)
- Constants: `pi`, `e`, `phi`, `tau`
- Factorial `5!` and combinatorics: `fact`, `gcd`, `lcm`, `perm`, `comb`
- Statistics: `sum`, `avg`, `mean`, `median`, `min`, `max`
- Boolean & comparison expressions: `2+2 >= 3`, `5 == 5`, `5 ~= 6`
- Bitwise functions plus infix operators: `5 & 3`, `12 | 3`, `12 ~ 10`,
  `1 << 4`, `16 >> 2`
- Vectors: `vec`, `dot`, `cross`, `mag`, `norm`
- Percentages: `20% of 150`, `150 + 20%`, `50%`
- `ans` references the last accepted result
- Number bases: `0xFF`/`0b1010` input and optional hex/binary result items
- Scientific / fixed output notation (`notation`)
- Digit separators in input (`1_000_000`) and optional grouped result items
- Unit & currency conversion: `5 km to mi`, `convert(100, "c", "f")`
- Date math: `2024-01-10 - 2024-01-01`, `today + 3 days`
- Optional buffer variables (`buffer_variables`)
- Works inside comments; context gating per filetype/comment/operator
- Rich documentation popup with alternate forms (`show_documentation`)
- Copy the accepted result to a register (`copy_register`)
- Configurable result precision and equation separator
- The bare result, the full `expr = result`, and optional base/grouped items

================================================================================
INSTALLATION                                          *blink-calc-installation*

Using lazy.nvim, register blink-calc as a blink.cmp provider:

>lua
  {
    "saghen/blink.cmp",
    dependencies = { "joelazar/blink-calc" },
    opts = {
      sources = {
        default = { "lsp", "path", "snippets", "buffer", "calc" },
        providers = {
          calc = {
            name = "Calc",
            module = "blink-calc",
            opts = { show_equation = true },
          },
        },
      },
    },
  }
<

CONFIGURATION                                               *blink-calc-config*

Options are passed through the blink.cmp provider `opts` table:

>lua
  {
    show_equation = true,      -- extra "expr = result" item when typing '=' (boolean)
    show_bases = false,        -- extra hex/binary items for integer results (boolean)
    group_digits = false,      -- grouped item for large integers; true uses ',' or a custom separator string
    precision = 4,             -- decimal places used to tame floating-point noise (integer)
    separator = " = ",         -- text between expression and result in the equation item (string)
    angle = "rad",             -- angle unit for trig functions: "rad" or "deg"
    notation = "auto",         -- numeric output: "auto", "fixed", or "scientific"
    show_documentation = true, -- show hex/binary/scientific/grouped forms in the docs popup (boolean)
    min_length = 0,            -- minimum expression length before completing (integer)
    require_operator = false,  -- require an operator so bare numbers do not complete (boolean)
    comment_only = false,      -- only complete inside comments or strings (boolean)
    disabled_filetypes = {},   -- filetypes in which the source is disabled (string[])
    buffer_variables = false,  -- resolve `name = expr` assignments from earlier lines (boolean)
    copy_register = false,     -- register to copy the accepted result into, e.g. "+" (false or string)
    currency_rates = {},       -- currency code -> value in a shared base unit
                               -- (table; an async provider invoked as
                               -- provider(done); or a built-in name, e.g.
                               -- "er-api"; providers pulled once per day)
    currency_cache_ttl = 86400, -- seconds a provider's rates are reused (integer)
  }
<

USAGE                                                        *blink-calc-usage*

Type a math expression and the completion menu shows the result:

- `2+2=`           → `4` and `2+2 = 4`
- `10*5+3`         → `53` and `10*5+3 = 53`
- `sqrt(16)`       → `4`
- `5!`             → `120`
- `gcd(12,18)`     → `6`
- `avg(2,4,6)`     → `4`
- `20% of 150`     → `30`
- `150 + 20%`      → `180`
- `band(12,10)`    → `8`
- `5 & 3`          → `1`; `1 << 4` → `16`
- `2+2 >= 3`       → `true`
- `sin(30)`        → `0.5` (with `angle = "deg"`)
- `dot(vec(1,2,3), vec(4,5,6))` → `32`
- `ans + 2`        → adds `2` to the last accepted result
- `5 km to mi`     → `3.1069`; `convert(100, "c", "f")` → `212`
- `2024-01-10 - 2024-01-01` → `9`; `today + 3 days` → a date
- `0xFF`           → `255` (with `show_bases`, also `0xFF`, `0b11111111`)
- `1_000_000`      → `1000000` (with `group_digits`, also `1,000,000`)
- `1500000`        → `1.5e+06` (with `notation = "scientific"`)

TROUBLESHOOTING                                    *blink-calc-troubleshooting*

First, run the health check:
>vim
  :checkhealth blink-calc
<

Then reproduce in a clean environment:

1. Clone blink-calc and cd into the directory
2. Run `nvim -u repro/repro.lua`
3. Run `:checkhealth blink-calc`
4. Reproduce the issue
5. Report repro.lua and any error messages
